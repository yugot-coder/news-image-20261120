# news-image-20261120 — The World Today

One image that sums up the world news of Friday 20 November 2026:
Cyclone Akvan's landfall on India's east coast, the first three-way
Trump–Xi–Putin summit in Shenzhen, the strike on the Crimean Bridge,
a record Van Gogh sale, and Nicholls' unbeaten 113 for New Zealand.

`main.py` (pure Python 3.13 standard library, no network) draws the
front page and writes it to `/output/entry.png` (1024x1024 PNG).
Run it locally with:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Entry for the make.fun competition `news-image-20261120`.
